# Figure contract for the application and repetition extension

Backend: Python, explicitly selected by the user; matplotlib for plots, Python PDF rendering for visual review. Source data are audited JSON artifacts. No private plotting template is used.

## Application byte ratios
1. Claim: request popularity changes dictionary frame ratios, but larger value payloads dilute the normalized node-saving benefit; complete frames are the denominator.
2. Evidence: four panels for N=4096/16384 × value32/1000, confirmation domain, all four q values; uniform and finite-Zipf lines for dictionary. All three bundle ratios shown as points and median/range, no fitted curve. Ordinary parity shown. Development gate values appear in a separate text/table rather than hiding failures in a confirmation-only graph.
3. Archetype: quantitative grid; all panels needed to distinguish population and payload dimensions.
4. Backend: Python only.
5. Export: 170 mm × 100 mm, PDF and SVG with editable text plus 300-dpi PNG; source-data JSON; error bars min/max of three fixed lists, never confidence intervals. No inference from five identical byte repetitions. No cropping of data or selection by outcome.

## Process spread
1. Claim: decision agreement across processes coexists with variable absolute timings.
2. Evidence: empirical cumulative distributions of max/min of five absolute median times, all 576 domain/cell/mode summaries per workload. 1.20 reference and counts; modes are not independent statistical samples.
3. Archetype: single quantitative comparison, validation role.
4. Backend: Python only.
5. Export: 170 mm × 72 mm, same formats; x-axis starts at 1 and includes every maximum. ECDF is descriptive, no inferential interval or significance label. Source JSON retains all individual spreads and paired-ratio ranges.

## Allocation probe
1. Claim to be confirmed only after registered probe: retained, primed writers can change encode allocation flow while native verification still allocates. The figure reports all outcomes, even if the hypothesis fails.
2. Evidence: four fixed fixture panels, three representations, fresh and primed-reset encoding bytes/op; separate table/text for decode and verification to avoid conflating stages. Five batch points and min/max bars per group, log scale if needed to show magnitude.
3. Archetype: quantitative grid, mechanism evidence.
4. Backend: Python only.
5. Export: 170 mm × 100 mm, same formats; five technical batches of 32 operations, one process, not independent experiments. Excludes retained writer initialization from the counter; not peak memory, memory residency or latency. Raw source counters and all stages remain available. Check zero values before choosing log scale.

All legends/captions define denominators, domain, n, aggregation and variation. Review PDF and PNG at final manuscript size, check font embedding and clipped labels. Existing validated controlled-corpus figures are copied unchanged.
