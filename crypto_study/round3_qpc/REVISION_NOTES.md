# 本轮实质修订说明

## 完成内容

现稿从“固定参考实现中的压缩收益”改为“稀疏 Merkle 证明传输对基线和原生表示的敏感性”。新增完整二进制基线、二进制 bitmap、两者的 zlib 组合，以及固定提交的 Celestia SMT 外部比较。旧基线与所有已注册 Round2 源码保持原哈希，原稿与已交付文件保留。

文献和适配分析先于新实现，PLAN 先于正式运行。新增 Python 测试 25 项，Go 包装器/字节恒等式/时钟回归测试 3 项，上游原有测试也通过。pytest 退出时第三方 pyreadline 控制台清理打印了异常，测试进程返回 0，断言无失败；不把该清理异常称为“输出完全干净”。

首轮正式实验因外部时钟分辨率不足而汇总失败。全部记录保留，先用探针定位，再另行预注册 QPC 修正，保持输入与判定标准不变重跑。修正实验共 11,340 条计时记录，实际进程退出 0。独立核对了 540 份报文、4,752 次外部证明验证及所有配对汇总与字节恒等式。

## 对结论的实质影响

- 在原宿主上，二进制 bitmap 相对二进制 full 的中位配对总耗时减少 2.68%–9.78%，通过本轮 12 个单元的判定。
- 原 JSON bitmap 相对新二进制 full 反而慢 15.08%–24.90%，虽然报文仍更小。原结果不能直接推广到更强基线。
- 外部 compact 相对原生普通证明的中位配对总耗时增加 14.41%–36.22%，24 个单元均未通过联合判定。72 组报文中 28 组更大。
- 外部 1,188 份证明中 778 份没有可省略的占位节点。实际帧长度完全满足已写明的字节恒等式，能解释元数据超过省略收益的情形。未用猜测解释缓存、GC或调度影响。

摘要、引言、相关工作、讨论和结论已围绕这些结果重组。旧注册设计和旧结果单列，未回溯改动其阈值。新增两个表和一张图，包含负结果。还纠正了旧文对首次启动失败原因过于确定的表述，原始记录仍保留。

## 尚未完成的研究能力

本轮完成的是建议中的强基线与外部实现筛选关口。由于外部联合门槛失败，没有继续宣称或实现普遍获益的自适应选择器；没有将并发、网络、RSS或新安全定理写成已完成结果。若继续这些研究，需新的具体假设、直接先例排查和预注册。

本文现在的比较更公平、负结果和适用范围更清楚，但仍是一篇有限的实证研究。新的协议能力、可迁移的性能预测方法和真实服务场景验证尚未建立，因此不能据此声称已达到 DIBOS 的协议贡献深度或可以保证 CCPE 接收。

本实验为单种子，存在随机噪声风险。作者信息、公共数据仓库、许可与投稿前人工复核等事项仍未补造。
