# 对标 CCPE 实证论文后的改进结果

本轮参考 StarPU 论文的条件分析，以及单节点框架论文的同任务对照结构，保留稀疏 Merkle 证明场景，重做主要问题与实验。没有把已知节点省略、字典去重或压缩器复用包装成新算法。旧稿、旧预注册、旧实验和负结果全部保留。

## 做了哪些实质改动

1. 同一 Celestia SMT 宿主、同一 SHA-256、同一逐证明验证接口，固定版本和训练以外的全部运行规则。新增字典表示是可选开关；默认仍是普通二进制。288 个旧帧逐位重放一致。
2. 采用合法、无重复的查询，对照实际哈希路径上的聚类与散布；N=4096/16384，q=1/8/32/128，成员和不存在查询分开。聚类不等同真实应用中相邻的键。
3. 对照整个批次的 zlib，公平给予它跨证明共享机会。另做 fresh/Reset 生命周期干预，复用写入器但每帧清空历史；压缩帧逐位相同，解码与验证保持一致。
4. 先完成文献、适配与 PLAN，再冻结 37 个注册产物；后台正式实验完成 64 个域内条件、192 个批次、36,288 条计时记录。完整记录不是独立样本数量。
5. 重写英文稿的摘要、引言、方法、结果和讨论，增加两张论文图、三个结果表和明确标注的带宽算术模型。旧 JSON 实验缩为研究动机，新稿按研究问题组织。

## 主要结果与失败判定

| 问题 | 结果 | 能支持的结论 |
|---|---|---|
| 路径局部性是否改变字典相对字节收益 | 开发 8/8 达标；确认 8/8 同向。字节比差开发22.61–26.48、确认20.37–27.15个百分点 | 在本宿主和合法受控输入中，共享结构实质改变表示成本；不是新共享机制，也不代表真实请求频率 |
| Reset 是否在 q=1/8 全面提供至少10%开发收益并确认同向 | **不成立**。q=1 两域全通过；q=8 开发6/24、确认20/24 | 单查询下降33.90%–65.78%，不能推广为普遍加速；4个确认反向条件保留 |
| 是否有模式同时少20%开发字节、处理时间增加不超过5%，并确认方向 | **没有**。全部512个替代模式/域内条件的配对中位时间比都大于1.05 | 更小帧需要本地处理代价，不能宣布联合优势 |
| 字典是否优于强通用压缩基线 | q>=8 的144个批次中，zlib ordinary全部更小；字典在全部48个相应域内条件位于汇总Pareto前沿 | 字典提供的是字节与本地时间之间的折中，不是最优压缩率 |
| 先去重再zlib是否更好 | q>=8 中128/144个 zlib dictionary 比 zlib ordinary更大 | 组合已有模块也需实测，不能假定组合后必然获益 |

“个百分点”指 dictionary/ordinary 完整帧字节比之差，不是字典帧本身下降百分比。计时是本地墙钟时间，含编码、解码和普通证明验证；根获取认证、证明生成及计时后等价检查不在区间内。确认只核对预设方向，不能将其写成与开发域相同幅度阈值。附录带宽阈值是无排队、无重叠的算术模型，没有网络测量。

## 证据与诊断

独立 Python 复核重建4棵树，检查192个批次、1152帧、48,672个证明实例及对应篡改根拒绝，并独立重算所有配对、门控、Pareto结果和附录模型。全部与原始产物一致。Reset帧逐位相同由冻结Go在每次观察后的断言检查；它们未另存重复帧，Python独立重放只覆盖六种唯一格式。

精确字节恒等式解释了省略和字典的体积变化。阶段计时只能描述开销位置，没有单独GC、缓存或分配器探针，故不把生命周期失败归因于这些内部机制。154.0603ms的最大慢样本也完整保留。没有为得到更好结果修改门槛或重跑选优。

功能与核验记录包括17项Go顶层测试、9项分析测试、12项独立审计测试。启动器曾因PATH未包含现有MSYS工具而退出，未进入测量；补全环境后同一冻结方案运行成功。审计脚本首次因读取冻结前字段名而失败，修正审计器后通过；正式源码和产物未变。

方法复核另发现并以独立功能探针确认：保留的上游 compact 解码器在非法掩码的未用位被置位时，可能越界异常；两个合法对照通过。所有正式帧均由原生证明生成，合法帧的核验与本次计时结论不受影响。该缺口已写入英文稿，源码及实际结果保存在 `diagnostic_compact/`。研究实现不能直接作为接收不可信网络帧的生产边界；若修复，应另立版本并重新评估，不能修改冻结代码后继续沿用旧测量。

## 质量判断

相对旧稿，这次增强来自同任务控制、强基线与有反例的条件结论，已更接近所选两篇 CCPE 论文的实证论证方式。没有必要因为不存在联合胜者就丢弃全部工作，也没有依据宣布已经达到它们的发表质量。

目前仍是一个范围有限的工程实证研究：一个宿主版本、一台机器、一个种子、两个确定性标签域，没有真实请求轨迹、并发服务或跨机器验证。保留逐证明接口也使其不能回答原生 multiproof 的最优选择。论文价值在可复核的条件判断，方法创新仍低。公开归档、作者身份与最终人工核验是提交前事项；本轮未投稿。

**本实验为单种子，存在随机噪声风险。**
