# Sources supporting the serving extension

Prepared before formal Round 8 measurement. This is a targeted extension of the prior literature review, not a claim of exhaustive search.

1. **VeriBench**, PVLDB 16(9), 2023, DOI 10.14778/3598581.3598588. Official full paper previously inspected: https://www.vldb.org/pvldb/vol16/p2145-ooi.pdf . It distinguishes database/query processing, verification and broader client/server measurements. This motivates reporting the verified response path and distinguishing it from server-only capacity; it does not supply performance numbers for our SMT.
2. **RainBlock**, USENIX ATC 2021, 333–347. Official record/full paper verified: https://www.usenix.org/conference/atc21/presentation/ponnapalli . Witness compaction and cross-witness node bagging are prior techniques, not new contributions of our dictionary. RainBlock changes the distributed authenticated-data architecture; our extension retains a single existing proof verifier and tests interface-preserving representations.
3. **El-Hindi et al., Towards Merkle Trees for High-Performance Data Systems**, VDBS 2023, DOI 10.1145/3595647.3595651. Metadata and original abstract/passages verified; full PDF access was unavailable. Its concurrency-oriented tree work provides context, not a reproduced baseline. The Round 8 worker wrapper does not modify the tree algorithm.
4. **Go net/http and hash implementation**, pinned Go 1.27.3, local standard-library source plus official documentation https://pkg.go.dev/net/http . HTTP/1.1 sockets and bounded handlers provide the transport; each client owns one connection. The actual pinned SMT treeHasher uses mutable hash.Hash Write/Sum/Reset, and Encoder is explicitly sequential-use only. The inspected code therefore requires a private tree/hash and encoder context per worker even though data stores are read-only.
5. **wrk2 latency measurement discussion**, official author repository https://github.com/giltene/wrk2 . Closed-loop feedback can suppress offered load during pauses. We explicitly measure fixed outstanding-client concurrency, retain all attempts and report conditional closed-loop latency. This extension does not estimate fixed-arrival-rate SLOs, and it does not use wrk2's reported millisecond-scale timing behavior to measure submillisecond cryptographic stages.
6. **Linux netem manual**, https://man7.org/linux/man-pages/man8/tc-netem.8.html . It supports rate/delay interventions but has kernel-timing and queue limitations. Nominal link settings must be calibrated and disclosed. Both private veth endpoints have TSO/GSO/GRO disabled by the verified kernel ioctl constants; no host/shared-interface route or qdisc is changed.

All numerical improvements in the new paper section must come from the newly registered measurements. No source's speedup is transplanted into our results. Prior full-text/abstract verification distinctions remain in publication_20261024/review_revision/reference notes. Go distribution SHA-256 is checked against https://go.dev/dl/?mode=json . No cloud pip installation is needed.
